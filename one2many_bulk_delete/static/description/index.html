⚡ One2Many Bulk Delete

Efficiently delete multiple records from One2Many fields with just one click!

Odoo 16.0 | 17.0 | 18.0 | Version 1.0.0

📹 See It In Action

✨ Key Features

☑️

Checkbox Selection

Select multiple records easily with checkboxes in each row of your One2Many fields.

✅

Select All

Quickly select or deselect all records with a single click using the header checkbox.

🗑️

Bulk Delete

Delete all selected records at once with a confirmation dialog to prevent accidental deletions.

🔒

State-Based Control

Automatically hides delete functionality when parent records are in restricted states (done, posted, cancelled).

⚡

Real-time Updates

See selection count update in real-time as you select/deselect records.

🎯

Easy Integration

Simply add widget="one2many_bulk_delete" to any One2Many field in your XML views.

🔧 How It Works

  1. Select Records: Click checkboxes next to the records you want to delete
  2. Review Selection: See the count of selected records in real-time
  3. Click Delete: Press the "Delete Selected" button
  4. Confirm: Confirm your action in the dialog box
  5. Done! Records are deleted and changes are saved to the database

📦 Installation

  1. Download the module for your Odoo version from Odoo App Store
  2. Extract the module to your Odoo addons directory
  3. Restart your Odoo server
  4. Update the apps list in Odoo (Apps → Update Apps List)
  5. Search for "One2Many Bulk Delete" and install it
  6. Start using it in your One2Many fields!
💡 Multi-Version Support: This module is compatible with Odoo 16.0, 17.0, and 18.0. Make sure to download the version that matches your Odoo installation. The module uses standard web framework components that are stable across these versions.

💻 Usage

Add the widget to any One2Many field in your XML views:

<field name="order_line" widget="one2many_bulk_delete">
<tree>
<field name="product_id"/>
<field name="product_uom_qty"/>
<field name="price_unit"/>
</tree>
</field>

That's it! The bulk delete functionality will be automatically available.
